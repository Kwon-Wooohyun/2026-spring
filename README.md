2022130883 권우현 / kbo(프로야구)모의 주식 거래소 KBOstock

주요 탭
1. 시장 - 선수들 주가를 볼 수 있는 탭. 
- 타자는 타율*100,000, 투수는 1/방어율*100,000
- 급등주, 급락주 확인 가능
- 종목 클릭 시 주가확인 및 종목 토론(댓글)가능
- ETF: 특정 선수들의 성적의 평균으로 만든 ETF상품
(ex. 삼성전자: 삼성 라이온즈 주요 선수들 5명의 주가를 평균낸 상품)

2. 포트폴리오
- 총자산, 현금잔고, 총손익, 수익률 확인 가능
- 보유 종목의 포트폴리오 확인
- 거래내역 확인 가능

3. 퀴즈 도전
- 야구 상식 관련 퀴즈를 맞히면 가상의 돈을 얻을 수 있음
- 상중하 난이도 선택 가능, 각각 한 문제당 맞히거나 틀릴 떄마다 50, 30, 10만원씩 적립 또는 차감되는 시스템

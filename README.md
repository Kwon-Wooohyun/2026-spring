# 🎸 SYNCBAND — 온라인 합주 스튜디오

## 설치 및 실행

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 서버 실행
```bash
python app.py
```

### 3. 접속
브라우저에서 `http://localhost:5000` 열기

---

## 📁 파일 구조
```
band_app/
├── app.py              # Flask 백엔드 (메인 서버)
├── requirements.txt    # Python 패키지
├── templates/
│   ├── index.html      # 랜딩 페이지 (팀 생성/참가)
│   └── studio.html     # DAW 스튜디오 (합주 화면)
└── uploads/            # 업로드된 MP3 파일 저장
```

## 🎵 사용 방법

### 팀 리더 (첫 번째 사람)
1. 홈에서 닉네임 + 밴드 이름 입력 → **밴드 생성하기**
2. 생성된 **6자리 팀 코드**를 팀원에게 공유
3. **트랙 업로드** 버튼으로 본인 악기 연주 MP3 업로드
4. 악기 선택 → 파일 선택 → 업로드 (첫 트랙은 싱크 조절 없음)

### 팀원 (나머지 사람들)
1. 홈에서 닉네임 + 팀 코드 입력 → **입장하기**
2. **트랙 업로드** 버튼으로 본인 악기 파일 업로드
3. **싱크 조절 화면**에서 기준 트랙과 타이밍 맞추기
   - 파형을 보며 오프셋 슬라이더로 정렬
   - ▶ 미리듣기로 실제 소리 확인
4. 확인 → 저장

## 🎚️ 스튜디오 기능
| 기능 | 단축키 / 방법 |
|------|-------------|
| 재생/정지 | `Space` 또는 ▶ 버튼 |
| 처음으로 | `Home` 또는 ⏮ 버튼 |
| 싱크 이동 | 타임라인 클릭 |
| 볼륨 조절 | 트랙별 슬라이더 |
| 뮤트 | `M` 버튼 |
| 팀 코드 복사 | 코드 배지 클릭 |

---

## ⚠️ 주의사항
- 현재 버전은 인메모리 저장소 사용 (서버 재시작 시 팀 정보 초기화)
- MP3 파일만 지원 (파일당 최대 100MB)
- 동일 네트워크에서 여러 명이 사용하려면 `host='0.0.0.0'`으로 실행하고 IP 공유
- 프로덕션 배포 시 SQLite/Redis 등으로 영속성 추가 권장
